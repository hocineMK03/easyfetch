# EasyFetch

EasyFetch is a lightweight, promise-based HTTP client for Node.js, similar to Axios. It simplifies making HTTP requests and handling responses. For now it only support REST APIS but i am planning to add more as we go.
[![npm version](https://img.shields.io/npm/v/@hocinemk/easyfetch)](https://www.npmjs.com/package/@hocinemk/easyfetch)
[![license](https://img.shields.io/npm/l/@hocinemk/easyfetch)](LICENSE)
[![downloads](https://img.shields.io/npm/dt/@hocinemk/easyfetch)](https://www.npmjs.com/package/@hocinemk/easyfetch)

## Features
- Lightweight and easy to use
- Supports GET, POST, PUT, DELETE, PATCH
- Timeout handling
- Custom headers

npm install @hocinemk/easyfetch
